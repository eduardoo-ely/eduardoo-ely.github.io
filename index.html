Sobre Mim

Atuando como Data Analyst Jr na IXC Soft, combino minha base técnica em desenvolvimento Full-Stack com análise de dados no dia a dia. Trabalho com MariaDB e Looker para extração, consulta e visualização de informações estratégicas.

Atualmente no 5º semestre de Ciência da Computação, aplico conhecimentos de banco de dados e servidores tanto no suporte técnico quanto na análise de dados, unindo as duas frentes para entregar mais valor no meu trabalho.

Tenho também uma base em Java e desenvolvimento que me dá fundamento técnico — mas hoje meu foco é claro: dados. Do dia a dia com SQL e dashboards até a construção de pipelines, estou direcionando tudo para a área.

Meu plano de carreira é evoluir de Data Analyst para DBA (Database Administrator) e, em seguida, Engenharia de Dados — passando por ETL e Governança, unindo experiência técnica com gestão estratégica de informações.
